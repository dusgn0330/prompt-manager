# 나만의 프롬프트 관리 프로그램

AI에게 입력했던 프롬프트를 한곳에서 관리하는 Python 콘솔 프로그램입니다.
프롬프트를 추가하고, 카테고리별로 보고, 키워드로 검색하고, 자주 쓰는 프롬프트는 즐겨찾기로 관리할 수 있습니다.
외부 라이브러리 없이 Python 기본 문법만 사용했습니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다.
2. 저장소를 내려받습니다.
   ```
   git clone https://github.com/dusgn0330/prompt-manager.git
   cd prompt-manager
   ```
3. 프로그램을 실행합니다.
   ```
   python prompt_manager.py
   ```

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 등록 (빈 값이면 다시 입력) |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호, 카테고리, 제목, 즐겨찾기 여부(⭐)와 함께 출력 |
| 3 | 카테고리별 조회 | 카테고리를 선택해 해당 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 키워드가 제목 또는 내용에 포함된 프롬프트 검색 |
| 5 | 프롬프트 상세 보기 | 번호를 입력해 제목, 카테고리, 즐겨찾기 여부, 내용 전체 출력 |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기 추가 또는 해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 출력 |
| 0 | 종료 | 프로그램 종료 |

- 프로그램 실행 중 추가한 프롬프트와 즐겨찾기 상태는 실행 중에만 유지되며, 종료하면 초기화됩니다.
- 잘못된 번호를 입력하면 안내 메시지가 나오고 메뉴가 다시 표시됩니다.

## 등록된 프롬프트 카테고리

| 카테고리 | 설명 |
|---|---|
| 텍스트 생성 | 글, 보고서, 메일 등 텍스트를 만드는 프롬프트 |
| 이미지 생성 | 이미지 생성용 키워드와 지시문 |
| 영상 생성 | 영상, 스크립트 제작용 프롬프트 |
| 페르소나 | AI에게 역할을 부여하는 프롬프트 |
| 자동화 | Make, Zapier 같은 노코드 자동화 설계용 프롬프트 |
| 기타 | 위에 속하지 않는 프롬프트 (직접 입력한 카테고리도 사용 가능) |

## 기본 등록 프롬프트

이전 미션에서 작성한 프롬프트를 바탕으로 5개가 기본 등록되어 있습니다.

- 자동화 워크플로우 설계 도우미 (자동화)
- 기상청 API 데이터 가공 도우미 (자동화)
- 자동화 도구 비교 보고서 (텍스트 생성)
- 우산 알림 메일 문구 작성 (텍스트 생성)
- 노코드 자동화 멘토 (페르소나)

## 코드 구조

| 함수 | 역할 |
|---|---|
| `show_menu()` | 메뉴 출력 |
| `add_prompt()` | 프롬프트 추가 |
| `show_list()` | 전체 목록 출력 |
| `show_by_category()` | 카테고리별 조회 |
| `search_prompt()` | 키워드 검색 |
| `show_detail()` | 상세 보기 |
| `toggle_favorite()` | 즐겨찾기 추가 및 해제 |
| `show_favorites()` | 즐겨찾기 목록 출력 |
| `main()` | 메뉴 선택을 받아 기능 실행 |

## 데이터 구조

프롬프트는 리스트 안의 딕셔너리로 저장합니다.

```python
prompts = [
    {
        "title": "제목",
        "content": "내용",
        "category": "카테고리",
        "favorite": False
    }
]
```
